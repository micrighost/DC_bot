# 🐸 Discord 綜合功能機器人 (AI記憶聊天 X 量化財經 X 語音音樂)

本專案是一個基於 `discord.py` (v2+) 架構開發的模組化 Discord 機器人。主程式採用物件導向設計（Cog 機制），完美整合了 **AI 記憶青蛙聊天室**、**台股量化籌碼技術面分析大腦** 以及 **智慧型 YouTube 下載播放音樂系統**。

藉由外接 PostgreSQL 資料庫與 FinMind 財經套件，本機器人不僅能進行有溫度的長短期對話、一鍵分析台股結構，還能化身為你的專專屬雲端點歌姬。

## 🛠 系統環境變數需求 (.env)
請在專案根目錄建立 `.env` 檔案，並填入以下完整設定：

```env
# Discord 機器人金鑰
DISCORD_TOKEN=your_discord_bot_token

# AI 核心設定 (OpenAI 規範端點，相容 Gemini、Ollama、OpenAI 等)
AI_API_URL=https://example.com
AI_MODEL=your_ai_model_name
AI_API_KEY=your_ai_api_key_or_any_string

# 資料庫連線設定 (PostgreSQL)
DB_URL=postgresql://user:password@localhost:5432/dbname
```

> ⚠️ **開發者重要提示 (Discord 權限設定)**：
> 本機器人啟用了 `message_content`（讀取訊息內容）與 `voice_states`（語音頻道狀態）特權意圖。請務必前往 [Discord Developer Portal](https://discord.com)，在你的 Bot 頁面將 **Message Content Intent** 勾選開啟，否則機器人將無法正常運作！

## 🌟 核心模組功能介紹

### 1. 🎵 智慧混和型音樂播放器 (`commands.music`)
內建高度自動化的語音串流控制系統，支援「本地快取」與「雲端即時下載」雙模操作：
* **智慧雙模點歌**：
  * **本地快取模式**：輸入純歌名時，系統會自動比對本地 `songs/` 目錄。內建精準字串提取，無論使用者輸入「包含副檔名（如 `test.mp3`）」或「純字串檔名（如 `test`）」皆能秒級識別並直接播放，節省網路頻寬。
  * **雲端下載模式**：偵測到 `http` 網址時，會自動調用 `yt-dlp` 高效組態，將 YouTube 影音即時提取為 128kbps 的高品質 `.mp3` 音訊並永久儲存至本地，達成「聽過即收藏」效果。
* **無限隨機電台 (`randomplay`)**：利用 FFmpeg 的 `after` 非同步回呼機制，在歌曲播放完畢後自動隨機挑選下一首歌曲，並透過 Bot Loop 派發通知，建立永不中斷的語音電台。
* **環境友善檢測**：模組載入時會自動執行 `shutil.which("ffmpeg")`，自動在後台檢查伺服器是否已正確配置 FFmpeg 執行檔路徑。

### 2. 📅 綜合籌碼與技術面分析 (`commands.daily`)
針對台灣股市設計的**量化實戰大腦**，只要輸入股票代號，機器人就會自動完成以下分析鏈：
* **官方套件對接**：透過 `FinMind` 官方套件非同步抓取目標個股過去 90 天的日 K 價格、三大法人買賣超、以及融資融券餘額。
* **原生 Pandas 指標計算**：擺脫難以安裝的 TA-Lib 依賴，直接用 `pandas` 精準演算：**SMA20、SMA60、RSI14 以及布林通道上下軌**。
* **獨創外資多空均線交叉**：精算過去 21 天外資淨買賣超的 **5MA** 與 **20MA**。透過籌碼均線的黃金交叉與死亡交叉，透視主力是正在「低檔吸籌」還是「高檔出貨」。
* **散戶動向籌碼對比**：結合最新一日的融資與融券餘額變化，看穿當前市場是「散戶接外資飛刀」還是「主力抬轎、散戶軋空」。
* **高相容 AI 實戰解讀**：將所有複雜的量化數據封裝進單一 Prompt，交由 AI 化身資深台股分析師，在 1000 字內快速輸出精準的壓力、支撐位與明日操盤策略。

### 3. 🐸 青蛙 AI 智能聊天室 (`commands.chat`)
一個具備「長短期記憶循環機制」與幽默台客青蛙人設的通用聊天模組：
* **台灣青蛙人設**：化身住在台灣、友善幽默的青蛙，結尾自帶可愛的「呱」叫聲。
* **短期記憶（快取）**：利用 PostgreSQL 的 `frog_recent_chats` 資料表保存最近 20 條對話。
* **長期記憶（壓縮循環）**：當短期對話累積滿 20 條時，會自動觸發「記憶整理助手」將所有歷史紀錄壓縮成 100 字內的「記憶精華」存入 `frog_summary`，並清空短期快取。下次對話時，AI 會頂著「長期回憶」繼續聊，徹底解決 Token 爆炸與 AI 失憶的問題。
* **Render 平台相容**：內建自動修正連線字串機制，可完美將 Render 預設的 `postgres://` 修正為 `postgresql://`。

## 🎲 機器人指令說明 (Commands)

### 📌 通用核心
* `!help` - 顯示目前所有註冊在機器人身上的可用指令與其詳細描述（覆寫預設，自動動態抓取）。
* `!ping` - 測試 Bot 是否在線，機器人會回應：`呱`。

### 🎵 音樂模組
* `!play <歌名 或 YouTube網址>` - 播放音樂。若輸入歌名則在本地尋找；輸入 YouTube 網址則下載後播放。
* `!stop` - 停止播放音樂並讓機器人斷開並退出當前的語音頻道。
* `!list` - 顯示目前伺服器硬碟中 `songs/` 資料夾內已下載的所有歌曲清單（超過 1900 字會自動程式碼塊切片分段傳送）。
* `!randomplay` - 開啟隨機電台模式，連續不間斷隨機播放本地下載好的所有歌曲。
* `!delete <完整檔案名稱>` - 從伺服器硬碟中刪除指定的歌曲檔案（例如：`!delete 剛好遇見你.mp3`）。

### 📈 財經分析模組
* `!daily <股票代號>` - 進行該個股的籌碼與技術面實戰解讀。
  * *範例：`!daily 2330` 或 `!daily 2454`（支援自動清除 `.TW` 等後綴的 Bug 修正機制，預設為 2330）。*

### 🐸 AI 聊天模組
* `!chat <訊息>` - 與青蛙助理開始長短期記憶對話。
  * *範例：`!chat 你還記得我上次說我喜歡吃什麼嗎？呱`*
* `!resetchat` - 讓青蛙喝下忘情水。一鍵徹底清空你在資料庫中的長期記憶精華與短期對話紀錄。

## 🚀 快速開始與環境部署

### 1. 系統依賴組件安裝 (必要)
由於音樂播放功能依賴底層解碼器，請確保你的作業系統已安裝 **FFmpeg** 且已將其路徑加入系統環境變數（PATH）中。
* **Windows**: 可透過官方網站下載 `ffmpeg.exe` 並設定環境變數。
* **Ubuntu/Linux**: `sudo apt update && sudo apt install ffmpeg`
* **Mac**: `brew install ffmpeg`

### 2. 安裝 Python 依賴套件
請確保你的執行環境已安裝 Python 3.8+，並在專案根目錄執行以下命令一鍵安裝所有依賴項目：
```bash
pip install -r requirements.txt
```

### 3. 啟動機器人
```bash
python DC_bot.py
```
當終端機顯示 `✅ 成功載入 commands.xxx` 且輸出 `已登入：<你的機器人名稱>` 時，即代表機器人已成功上線！
